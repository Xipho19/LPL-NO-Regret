# LPL：不留遗憾

LPL 文字决策游戏。你以选手身份坐上 BP 席，在 8 个关键节点做出选择，改写历史。

## 在线试玩

- GitHub Pages：https://xipho19.github.io/LPL-NO-Regret/

## 游戏内容

4 个经典比赛章节：

| 章节 | 比赛 | 可选位置 |
|------|------|----------|
| BLG 2024 | 全球总决赛 vs T1 | 上野中下辅 |
| RNG 2018 | 全球总决赛 vs G2 | 上野中下辅 |
| TES 2020 | 全球总决赛 vs FNC | 上野中下辅 |
| JDG 2023 | 全球总决赛 vs T1 | 上野中下辅 |

每局 8 个关键节点，每个节点 3 个选项：

- **A 稳健**：90% 成功，只加经济，不加评分
- **B 常规**：50% 成功，加经济 + 对应评分维度
- **C 高风险**：30% 成功，加更多经济 + 更多评分维度

## 数值系统

5 维评分加权计算最终得分：

| 维度 | 权重 |
|------|------|
| 经济 | 25% |
| 视野 | 15% |
| 配合 | 20% |
| 节奏 | 20% |
| 对线 | 20% |

`score > 2.5` → 本局胜利，否则失败。BO5 系列赛先赢 3 局获胜。

## 直播模块

虎扑 NBA 文字直播风格：

- 主播消息逐条弹出（1 秒/条），慢慢向下滚动
- 选完选项后立刻反馈成功/失败 + 经济变化
- 后续节点的消息根据当前局势动态变化（优势/均势/劣势三套文案）
- 打完最后一局后播报推水晶/被推水晶的结束话术
