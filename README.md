# 不再遗憾 · LPL 文字决策游戏

可玩的本地网页原型。零构建依赖，Node.js 18+。

## 启动

`npm start`，打开 http://127.0.0.1:4173 。

`npm test` 验证决策、胜负分支、回溯、存档验证与历史阵容绑定。

## 当前内容

- 免费章节：2024 全球总决赛 BLG vs T1 决赛第五局，五位 BLG 选手可选。
- 额外章节：2018 全球总决赛 RNG vs G2 八强第五局，五位 RNG 选手可选，模拟激励广告解锁一次完整体验。
- 选人、赛前简报、八次文字直播决策、动态局势、闪现与大招状态、结局、免费基础复盘、深度分支分析、本地存档、重开和回溯。
- 无强制插屏。只有失败回溯、赛后深度复盘、额外章节三个自愿广告点位。

## 真实性与素材

名单、英雄、版本、日期、历史结果核对于 Games of Legends：

- https://gol.gg/game/stats/62820/page-game/
- https://gol.gg/game/stats/14513/page-game/

从 00:00 介入，此后所有直播与数值均为简化战术推演，不是录像重建。对手响应当前视野与接应状态；玩家无法直接操作其他选手。此原型尚不包含完整伤害、装备、兵线、技能射程、等级与寻路模拟。

英雄头像固定使用 Riot Data Dragon 14.18.1 与 8.19.1，按版本分目录；图片加载失败自动降级为文字。**尚未找到可核实年份的队标与定妆照，故未加入这些图片**。不得使用现役头像自动覆盖历史素材。

## 广告集成

`app.js` 的 `DemoAdProvider.show(placement)` 是开发版模拟，界面明确标注。将其替换为正式广告 SDK；只在 SDK 的奖励完成事件中返回 `{ completed: true }`。取消、失败和中断返回 false，不能发奖励。广告不增加战力或改变阵容。正式上线需服务端验证奖励事件、防止重复回调。

三个 placement：`rewind`（失败回溯），`deep`（深度复盘），`chapter`（额外章节）。

基础复盘提供终局达标情况和每次决策的数值结算。深度复盘独立展示整局根因、关键转折、最后节点能否挽回、逐节点两条替代分支、最少改动获胜路线，以及所选角色与当局对手阵容的战术参考。替代分支调用同一引擎，只改当前选择、固定后续选择；最少改动路线搜索完整八节点，不代表唯一解或真实比赛胜率。技能、兵线与伤害尚未完整模拟，报告不能用于归因真实选手失利。

## 文件

- `data.js`：年份隔离的比赛档案、角色、英雄、八个推演节点。
- `engine.js`：纯函数状态推进、存档校验、回溯。
- `review.js`：基于真实游玩路径的因果分析、反事实重算与最少改动路线搜索。
- `commentary.js`：八阶段行动解读，结合所选角色、行动前条件、上一轮决定、实际数值与技能冷却；旧存档记录在展示时生成新版解读，不改写存档或胜负规则。
- `app.js`：完整游玩流程、存档与模拟广告。
- `styles.css`：桌面与移动布局。
- `assets/manifest.json`：素材来源与核实状态。

本地原型，不代表已获官方授权、已部署上线或已接入正式商业广告。
# 手机体验与阶段取舍

首页为固定 390 × 844 的手机预览，实际游戏入口为 `game.html`。新局使用第二版规则：换线与胜负手等待会扣除 500 机会成本；大龙区和胜负手主动行动要求视野 3，其余要求 2，接应均要求 2。上单换线、打野大龙区域、中单首次联动、ADC 正面交锋、辅助胜负手的成功主动行动额外获得 150 经济。资源交换获得 540 经济并牺牲协同。旧存档继续使用原版规则，复盘按各局规则重算。

失败回溯：完成激励广告后，从全部 8 个节点中任选一处，恢复到该次决策之前；之前的选择保留，该节点及后续选择重新进行。关闭节点弹窗不会消耗已领取奖励，奖励随本局存档保留；确认回溯后消耗一次奖励。
